# Heritage image sources

The prototype intentionally keeps image binaries out of the repository to keep the demo lightweight. Heritage records use public image URLs in `src/data/demoHeritage.js` and the backend seed data.

Primary image sources used:
- Wikimedia Commons: Taj Mahal, Hawa Mahal, Konark Sun Temple, Red Fort, Sanchi Stupa, Madhubani Painting, Pattachitra, Bharatanatyam.
- Unsplash: Amber Fort, Khajuraho, Bhangarh, Diwali and a few visual fallback records.

For an offline/production build, download appropriately licensed images, place them in this folder, and replace the record URLs with `/images/<filename>`.
